# This page!

### Repository

- [GitHub](https://github.com/Monge1h/monge1h.com)

### Tech stack

- Next.js (static export)
- Tailwind CSS
- AWS: S3 + CloudFront, with infrastructure defined in Terraform
- GitHub Actions for CI/CD

I built this page because I wanted to put my design and layout skills into practice. I'm no expert, but I started with the design in Figma — you can see it [here](https://www.figma.com/file/bIykHp4bm9rKsOhhONHjGy/paginaweb?node-id=0%3A1) 👀

Over time it has become my personal playground: this is where I try out frontend, infrastructure and SEO ideas. The current version is available in English and Spanish, detects your language automatically at CloudFront, and is generated 100% statically.
