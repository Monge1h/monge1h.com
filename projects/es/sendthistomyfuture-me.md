# 🚧 sendthistomyfuture.me

No puedes hablar con tu pasado, pero sí puedes enviarle una carta a tu yo del futuro.

### 🚧 Proyecto en vivo

- [https://sendthistomyfuture.me](https://sendthistomyfuture.me)

### Repositorio

- [GitHub](https://github.com/Monge1h/sendthistomyfuture.me)

Actualmente estoy trabajando en este proyecto. A veces un recuerdo de nuestro pasado puede alegrarnos el día, así que con este proyecto puedes escribir tus pensamientos, aspiraciones y esperanzas de hoy, y recibirlas en el futuro como un recordatorio de quién eras.

## Tech stack

**Cliente:** Next.js, Chakra UI

**Servidor:** Node, NestJS, MongoDB
